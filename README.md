# WeChat Shop

**Explore a shop backend, from controllers to data models.**

A historical ASP.NET Core WeChat shop project for developers who want to explore controllers, models, server-rendered views, and Entity Framework data access.

## Source map

| Directory / file | Purpose |
| :--- | :--- |
| [`Controllers/`](Controllers/) | Shop administration and API controllers |
| [`Models/`](Models/) | Data models |
| [`EntityFramework/`](EntityFramework/) | Data access |
| [`Views/`](Views/) | Server-rendered views |
| `Startup.cs` / `Program.cs` | Application startup |
| `ztbiyesheji.csproj` | Project and dependency configuration |

## Project status

This historical source project targets `netcoreapp2.0`, with ASP.NET Core 2.0.8 and MySQL Entity Framework Core 8.0.13 dependencies. It is a source-exploration and modernization reference, **not a claim of current production readiness**. This documentation refresh does not verify building, running, or deploying the application.

No standalone license file is present in the repository root. Contact the author to clarify reuse permissions.
